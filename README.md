# 🎤 Top-Grossing Concert Tours Analysis

Data cleaning and exploratory analysis of the 20 highest-grossing concert tours.

## 🔍 What I Did
- Cleaned messy data (footnote markers, currency symbols, year ranges)
- Handled missing values without inventing data
- Validated average gross per show against actual gross ÷ shows
- Explored revenue, show count, and inflation effects

## 📌 Key Findings
- The Eras Tour (Taylor Swift) leads with **$780M**
- Revenue is driven by per-show earnings, not number of shows (correlation **−0.31**)
- Inflation adjustment lifts older tours by up to **+49.8%** (Cher)

Python · Pandas · NumPy · Seaborn · Matplotlib
